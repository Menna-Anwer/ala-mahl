# على مهل

مشروع Angular لتنظيم المذاكرة، بواجهة عربية تدعم الموبايل.

## التشغيل في VS Code

1. فكّي ضغط الملف، وافتحي مجلد `ala-mahl` الذي يحتوي على `package.json` في VS Code.
2. ثبّتي Node.js بإصدار **22.12 أو أحدث ضمن إصدار 22**، أو **24 LTS**.
3. افتحي Terminal داخل المجلد، وثبّتي المكتبات مرة واحدة:

```sh
npx --yes npm@11.16.0 ci
```

قد يطلب `npx` تنزيل npm المحدد. اتصال الإنترنت مطلوب للتثبيت فقط.

4. في أول Terminal شغّلي البيانات التجريبية، واتركيه مفتوحًا:

```sh
npm run api
```

5. افتحي Terminal ثانية في نفس المجلد:

```sh
npm start
```

6. افتحي http://localhost:4200 في المتصفح.

لإيقاف أي سيرفر، اضغطي `Ctrl+C` في الـ Terminal الخاصة به. إذا ظهر خطأ أن المنفذ مستخدم، أغلقي النسخة القديمة من السيرفر. الـ API تعمل على المنفذ 3000، والواجهة على 4200.

## جرّبي خطوة واحدة

من «الموضوعات» أضيفي موضوعًا، ثم «جلسة للموضوع». الجلسة هنا وقت للمذاكرة، وليست اجتماعًا. اكتبي ما ستذاكرينه، التاريخ والمدة، واحفظي. من بطاقة الجلسة يمكنك كتابة ما فهمتِه، وتحديد نقطة للمراجعة. ستظهر في «المراجعة»، وبعد تحديد أنها تمت ستجدينها في تبويب «تمت مراجعتها».

توجد أمثلة جاهزة في أسبوع **21 نوفمبر 2026**. لو فتحتِ المشروع في أسبوع آخر، استخدمي أسهم الأسبوع للوصول إليها أو أضيفي جلسات بتواريخك.

## البيانات وحدود النسخة

- `db.json` يخزن تعديلاتك محليًا أثناء تشغيل JSON Server. احفظي نسخة منه قبل تغييره أو نقل المشروع.
- `db.seed.json` نسخة من البيانات التجريبية الأصلية. لاستعادة الأمثلة: أوقفي السيرفر، احتفظي بنسخة من `db.json`، ثم انسخي محتوى ملف seed إليه. هذا يستبدل البيانات الحالية.
- أرشفة الموضوع لا تحذف جلساته، ويمكن إرجاعه من تبويب «مؤرشفة».
- هذه نسخة محلية تعليمية مكتملة للمسار المعروض، بباك اند تجريبي JSON Server، وليست خدمة جاهزة للنشر. لا توجد حسابات أو تسجيل دخول أو صلاحيات أو مزامنة أو تنبيهات أو ذكاء اصطناعي. لا تضعي فيها بيانات حساسة، ولا تعرضي JSON Server للإنترنت.
- فشل الاتصال يظهر برسالة وإعادة محاولة، والحفظ الفاشل لا يمسح النص المكتوب.

## تنظيم الكود

```text
src/app/
  core/                 # نماذج البيانات وخدمة HTTP والحالة
  features/
    week/page/          # الأسبوع والبحث والفلترة
    topics/page/        # إنشاء وتعديل وأرشفة الموضوعات
    sessions/page/      # نموذج الجلسة وتفاصيلها
    sessions/components/# بطاقة الجلسة
    review/page/        # نقاط المراجعة
  layouts/navbar/       # القائمة المتجاوبة
  shared/
    components/         # زر وبطاقة ورسائل حالة وحوار تأكيد
    form-controls/      # input وselect وtextarea وcheckbox منفصلة
    directives/         # تنسيق حالة الجلسة
    pipes/              # المدة وحالة الجلسة
    util/               # تواريخ محلية وأسبوع يبدأ السبت
```

المكونات standalone مع Angular Material وBootstrap RTL وSCSS وFont Awesome. مسار الـ API في `src/environments/environment.ts`. عناصر الفورم المشتركة تستقبل `FormControl`، مثال الاستخدام داخل `session-form.html`.

## الاختبار والبناء

```sh
npm run test:ci
npm run build
```

الاختبارات الآلية: 11 اختبارًا في 6 ملفات. يشمل ذلك الخدمة، التحقق من الفورم، التواريخ، pipes وdirective. تم أيضًا اختبار المسار من الواجهة مع JSON Server حقيقي محليًا، وحفظ الملاحظات بعد إعادة التحميل، والحذف والتراجع عنه، والأرشفة والاسترجاع، وعرض الموبايل.

البناء الناتج في `dist/ala-mahl/browser`. فتح `index.html` مباشرة ليس طريقة تشغيل مدعومة، لأن المشروع يحتاج سيرفر ومسارات Angular والـ API.

يوجد تحذير حجم للحزمة الأولى في بناء الإنتاج، والحد الأصلي 500 kB محفوظ. لا يمنع التشغيل. توجد تنبيهات اعتماديات متوسطة حسب التدقيق وقت التسليم، التفاصيل في `CHECKS.md`. لا تشغّلي `npm audit fix --force` تلقائيًا لأنه قد يغيّر إصدارات رئيسية.
